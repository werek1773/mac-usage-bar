## App Review notes

`Resubmission resolution for version 1.8.4 (build 28): The App Store name is now “ResourceLens: System Monitor”, while the installed application, bundle display, and executable names are “ResourceLens”. The previously flagged Apple product term has been removed from the app name, both localized subtitles, and all user-visible on-device names. The existing bundle identifier remains unchanged so current users can upgrade normally. The app now provides “Quit ResourceLens” in both the standard application menu and the status-item menu; Command-Q invokes the standard application termination action. Build 28 was created on a supported release Xcode Cloud environment after build 26 was rejected during automated binary processing with ITMS-90301.`

`ResourceLens is a menu-bar-only app (LSUIElement), so it does not show a Dock icon or a conventional main window. After launch, click the live readout in the menu bar, then choose “Open Dashboard”. The same menu includes a visible “Quit ResourceLens” command, and Command-Q uses the standard application termination flow. The app reads system metrics locally using public macOS APIs. It makes no network requests and collects no data. On a computer without a battery, the battery card correctly displays “No battery”. The App Store target intentionally excludes the direct-download build's memory optimization feature and does not request administrator privileges.`
